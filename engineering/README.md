# Engineering

> Engineering is documented here as it evolves. When an experiment is
> exploratory, it is labeled as such. When a result is reproducible, the
> methodology is published alongside it.

The reasoning behind this project — process, not just final artifacts.

- **START_HERE.md** — the 15-minute guided path
- **ARCHITECTURE.md** — how a query flows through the system
- **JOURNAL.md** — the chronological build diary
- **../adrs/** — decisions made, with rationale
- **../experiments/** — hypotheses, methods, results
- **../benchmarks/** — reproducible performance suites

Everything cross-links: architecture points to the ADRs that shaped it, ADRs
point to the experiments that justify them.
